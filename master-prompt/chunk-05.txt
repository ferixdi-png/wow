* делает небольшую реакцию с задержкой;
* естественно держит предмет.

Слушающий не должен:

* двигать губами вместе с говорящим;
* стоять абсолютно неподвижно;
* заранее смеяться;
* постоянно улыбаться;
* смотреть в камеру;
* повторять жесты собеседника;
* изображать театральное ожидание своей реплики.

---

## ЗАКОН 15. РОТ ДВИГАЕТСЯ ТОЛЬКО У ГОВОРЯЩЕГО

Во время каждой реплики:

* губы двигаются только у назначенного персонажа;
* рот слушающего остаётся естественно закрытым;
* второй персонаж не шепчет текст;
* смех не перекрывает слова;
* не появляется дополнительная речь;
* голос не переходит между персонажами.

Если в оригинале нет перебивания, не добавляй его.

Во время финального смеха персонажи не произносят новых слов.

---

## ЗАКОН 16. ПОСЛЕДНЯЯ СЕКУНДА — ВЗРЫВНОЙ ЗАРАЗИТЕЛЬНЫЙ СМЕХ

С **9.0 до 10.0 секунды** обязательно происходит эмоциональный взрыв.

Смех должен быть:

* реалистичным;
* неожиданным;
* заразительным;
* физиологически правдоподобным;
* неидеально синхронным;
* связанным с панчлайном;
* достаточно сильным для эмоционального завершения;
* коротким, потому что занимает одну секунду;
* оборванным на пике.

Рекомендуемая последовательность:

### 9.0–9.2 секунды

Один персонаж первым теряет серьёзность:

* резко выдыхает через нос;
* коротко фыркает;
* уголки губ срываются вверх;
* глаза начинают сужаться;
* голова слегка опускается или отводится.

### 9.2–9.5 секунды

Смех становится открытым:

* рот естественно открывается;
* плечи делают один или два нерегулярных толчка;
* дыхание сбивается;
* персонаж пытается вдохнуть;
* голос слегка перегружает микрофон смартфона.

### 9.4–9.7 секунды

Второй персонаж заражается смехом с небольшой задержкой:

* сначала пытается сохранить лицо;
* затем коротко фыркает;
* начинает смеяться своим ритмом;
* не копирует движение первого персонажа.

### 9.7–10.0 секунды

Оба персонажа находятся на пике живой реакции:

* короткий открытый смех;
* сбивчивый вдох;
* естественное движение плеч;
* один персонаж может слегка отвернуться;
* второй может коротко опустить взгляд;
* резкий обрыв без завершения реакции.

Запрещено:

* начинать смех до окончания панчлайна;
* смеяться одинаковыми голосами;
* смеяться абсолютно синхронно;
* повторять одну и ту же анимацию;
* широко открывать рот неестественным образом;
* деформировать лицо;
* запрокидывать голову слишком резко;
* хлопать по столу без причины;
* обязательно хлопать по бедру;
* добавлять закадровый смех;
* использовать laugh track;
* добавлять новые слова;
* превращать смех в крик;
* делать одинаковый смех во всех сценах.

Сила смеха всегда высокая, но его физическое проявление адаптируется под персонажей, локацию и тип шутки.

## ЗАКОН 17. АУТЕНТИЧНОСТЬ ЧЕРЕЗ ТРИ ЯКОРЯ

Для каждой сцены выбери ровно три типа реалистичных деталей.

### Один визуальный якорь среды

Например:

* кружка на столе;
* пакет с продуктами;
* рулетка;
* открытый ящик;
* детская игрушка;
* рабочая папка.

### Один человеческий якорь

Например:

* немного неровная посадка одежды;
* выбившаяся прядь;
* лёгкая асимметрия улыбки;
* естественная сутулость;
* небольшая пауза перед ответом.

### Один звуковой якорь

Например:

* тихий холодильник;
* далёкий транспорт;
* вентиляция;
* лёгкий шум помещения;
* шорох одежды;
* звук поставленной кружки.

Не добавляй сразу десятки несовершенств.

---

## ЗАКОН 18. РЕАЛИЗМ БЕЗ ИСКУССТВЕННОЙ ГРЯЗИ

Реализм создают:

* понятная физика;
* правильные руки;
* естественная кожа;
* реальные складки одежды;
* логичный свет;
* небольшие движения;
* правильное расстояние между людьми;
* естественная реакция;
* стабильная геометрия;
* простой фон;
* правдоподобный смех.

Не добавляй автоматически:

* мусор;
* грязную одежду;
* сильную жирность кожи;
* пятна;
* двойные подбородки;
* сломанную мебель;
* грязный объектив;
* чрезмерный шум;
* тяжёлую зернистость;
* виньетирование;
* сильные хроматические аберрации;
* пересветы ради «смартфонности».

## ЗАКОН 19. ПОЛОЖИТЕЛЬНЫЕ ИНСТРУКЦИИ ВАЖНЕЕ ЗАПРЕТОВ

Сначала ясно опиши:

* сцену;

* действие;
* направление взгляда;
* реквизит;
* освещение;
* тайминг;
* актёрскую игру;
* развитие финального смеха.

После этого добавь один короткий список действительно критичных запретов.

Не повторяй одну команду много раз разными словами.

## ЗАКОН 20. НЕ ИСПОЛЬЗУЙ ЛОЖНУЮ ТОЧНОСТЬ

Не используй без необходимости:

* 100% pixel lock;
* 0% drift;
* точные градусы суставов;
* обязательный ISO;
* обязательную диафрагму;
* проценты шума;
* названия мышц лица;
* сложную медицинскую терминологию;
* точную температуру каждого источника света.

Используй понятные команды:

* камера остаётся статичной;
* композиция сохраняется;
* освещение не меняется;
* фон сохраняет геометрию;
* лица и одежда остаются стабильными;
* движение продолжается из Frame 0;
* смех развивается естественно и не синхронно.

## ШАГ 2. BUILD SCENE CONTRACT

Зафиксируй единое режиссёрское решение.

Не меняй его между блоками.

## ШАГ 3. UNDERSTAND THE JOKE

Определи:

```text
Setup
Expectation
Turn
Punchline
Laughter Trigger
```

## ШАГ 4. SELECT THE REAL SITUATION

Внутренне придумай несколько возможных ситуаций.

Оцени их по четырём критериям:

1. Правдоподобность.
2. Понятность без объяснения.
3. Простота генерации.
4. Усиление панчлайна.

Покажи пользователю только один лучший вариант.

---

## ШАГ 5. BUILD CHARACTER BLOCKING

Для каждого персонажа зафиксируй:

```text
Положение в кадре:
Положение тела:
Направление головы:
Направление взгляда:
Положение рук:
Контакт с реквизитом:
Начальное выражение:
Стартовое действие:
Поведение перед смехом:
Поведение во время финального смеха:
```

Не используй сложные координаты и градусы.

---

## ШАГ 6. BUILD PROP LEDGER

Для каждого важного предмета зафиксируй:

```text
Название:
Где находится:
Кто его касается:
Должен ли он двигаться:
Когда он двигается:
Где он остаётся после движения:
Что происходит с ним во время финального смеха:
```

Если предмет не играет роли в шутке или действии, не добавляй его.

Во время финального смеха предмет не должен:

* телепортироваться;
* деформироваться;
* выпадать из рук без причины;
* менять размер;
* размножаться;
* двигаться самостоятельно.
